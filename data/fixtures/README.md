# Fixtures

Deterministic synthetic datasets generated by `scripts/generate_fixtures.py`.

**These contain no real market data.** They exist so that experiments are
reproducible without network access or credentials. A strategy that performs
well on them has demonstrated that the pipeline works, and nothing about any
real market.

Regenerate with:

```bash
python scripts/generate_fixtures.py
```

The script is idempotent — a diff after running it means the generator changed.
